# 相机震动工作流程

## 核心思路

当前相机震动使用 Cinemachine Impulse。

正式战斗中不直接修改 `Main Camera` 的 Transform，也不依赖 `CameraShakeManager`。命中逻辑只负责发出 Impulse 事件，当前正在工作的 Cinemachine 虚拟相机负责接收震动。

## 配置流程

```text
DamageHitConfigSO
  hitShake = CameraShakeUniformData
    channel = 1
    duration = 震动持续时间
    force = 震动力度
    dissipationDistance = 传播距离
    defaultVelocity = 配置震动方向

CameraHelper/CM FreeLook1
  CinemachineFreeLook
  CinemachineImpulseListener
    Channel Mask = 1
    Gain = 1
    Use 2D Distance = false

CameraHelper/CM Dual Target (1)
  CinemachineVirtualCamera
  CinemachineImpulseListener
    Channel Mask = 1
    Gain = 1
    Use 2D Distance = false

Main Camera
  Camera
  CinemachineBrain
```

注意：当前项目使用的 Cinemachine 版本中，`CinemachineImpulseListener` 是 `CinemachineExtension`，应该挂在虚拟相机上，不要挂在 `Main Camera` 上。

## 运行流程

```text
玩家动作命中敌人
        |
        v
ActionPlayer.CheckCollide()
        |
        v
CollideDetectionDelegate.Tick()
        |
        v
SelfCollideManager.HandleCollide(sliceId, collider)
        |
        v
SelfCollideManager.HandleDamageCollide()
        |
        v
SelfCollideManager.PlayHitEffects()
        |
        v
SelfCollideManager.ApplyHitShake()
        |
        v
DamageHitConfigSO.hitShake.GenerateShake(attackerPosition)
        |
        v
CameraShakeUniformData 创建 Cinemachine Impulse Event
        |
        v
当前 live 虚拟相机上的 CinemachineImpulseListener 接收 channel = 1 的事件
        |
        v
CinemachineBrain 将虚拟相机结果输出到 Main Camera
        |
        v
Game View 中看到相机震动
```

## 方向规则

震动方向由 `DamageHitConfigSO.hitShake` 中的 `CameraShakeUniformData.defaultVelocity` 配置。

```text
defaultVelocity = (0, 1, 0)   竖向震动
defaultVelocity = (1, 0, 0)   横向震动
defaultVelocity = (0, 0, 1)   前后震动
defaultVelocity = (1, 1, 0)   斜向震动
```

`defaultVelocity` 只表示方向，震动强度由 `force` 控制。

```text
想改变方向：改 defaultVelocity
想改变强弱：改 force
想改变时间：改 duration
```

## Channel 规则

```text
CameraShakeUniformData.channel
        |
        v
CinemachineImpulseListener.Channel Mask
```

只有两边频道匹配时，相机才会接收震动。

最小验证阶段统一使用：

```text
channel = 1
Channel Mask = 1
```

后续可以按类型拆分：

```text
1 = 普通命中震动
2 = 重击震动
4 = 爆炸震动
8 = 演出震动
```

## PlayerTest 最小验证

```text
CameraHelper/CM FreeLook1
  添加 CinemachineImpulseListener

CameraHelper/CM Dual Target (1)
  添加 CinemachineImpulseListener

Assets/GameDev/Player/attack01_1.asset
  hitShake = CameraShakeUniformData
    channel = 1
    duration = 0.15
    force = 1.2
    dissipationDistance = 100
    defaultVelocity = (0, 1, 0)
```

命中后 Console 应出现：

```text
[HitShake] Cinemachine impulse triggered.
```

如果有日志但画面不震，优先检查：

```text
当前 live 虚拟相机是否挂了 CinemachineImpulseListener
Listener 的 Channel Mask 是否包含 hitShake.channel
Listener 的 Gain 是否大于 0
DamageHitConfigSO.hitShake 是否为空
```
