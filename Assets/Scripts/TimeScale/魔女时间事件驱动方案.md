# 魔女时间事件驱动方案

## 目标

完美闪避只负责判断自己是否满足触发条件和冷却条件。魔女时间执行器不判断角色冷却，也不绑定具体角色输入，它只响应事件、下发时间缩放命令、广播运行状态。

## 文字流程图

```text
玩家闪避判定
    |
    | 命中敌方攻击判定，并且处于完美闪避窗口
    v
角色自身冷却判断
    |
    | 冷却通过
    v
触发 GlobalEvents.OnWitchTimeRequested
    |
    | WitchTimeRequest
    | - commandId
    | - sourceId
    | - casterId
    | - duration
    | - worldScale
    | - selfScale
    | - affectedType
    | - playPolicy
    v
WitchTimeExecutor
    |
    | 注册 TimeScaleWitchCommand
    v
TimeScaleManager
    |
    | 对所有已注册 TimeScaleDispatcher 的对象重新计算缩放
    v
角色 / 子弹 / 特效 / 音频按 TimeScaleType 应用缩放
```

## 生命周期事件

```text
OnWitchTimeRequested
    |
    v
OnWitchTimeStarted
    |
    v
OnWitchTimeUpdated
    |
    v
OnWitchTimeStopped
```

UI 提示、屏幕特效、音效、后处理可以只监听 Started / Updated / Stopped，不需要引用闪避逻辑，也不需要引用 TimeScaleManager。

## 职责边界

```text
完美闪避触发方
    - 判断是否处于完美闪避窗口
    - 判断角色自己的魔女时间冷却
    - 组装 WitchTimeRequest
    - 触发 OnWitchTimeRequested

WitchTimeExecutor
    - 监听 OnWitchTimeRequested
    - 根据 playPolicy 处理已有魔女时间
    - 添加或移除 TimeScaleWitchCommand
    - 广播 Started / Updated / Stopped

TimeScaleManager
    - 维护时间缩放命令
    - 每帧更新命令剩余时间
    - 合并并应用最终缩放
```

## 重入策略

```text
IgnoreIfActive
    已经有魔女时间时忽略新请求。

Restart
    移除旧命令，从新请求的 duration 重新开始。

RefreshDuration
    移除旧命令，用新请求的 duration 刷新持续时间。

ExtendDuration
    将当前剩余时间和新请求 duration 相加，再重新下发命令。
```

因为当前 TimeScaleMode.AddCommand 使用 TryAdd，同一个 commandId 无法覆盖已有命令，所以 Restart / RefreshDuration / ExtendDuration 都需要先 RemoveCommand，再 AddCommand。

## 触发示例

```csharp
GameApplication.Instance.EventCenter.TriggerEvent(
    GlobalEvents.OnWitchTimeRequested,
    new WitchTimeRequest
    {
        commandId = "PerfectDodge_WitchTime_Player",
        sourceId = "PerfectDodge",
        casterId = playerId,
        duration = 1.5f,
        worldScale = 0.1f,
        selfScale = 1f,
        affectedType = TimeScaleType.All,
        playPolicy = WitchTimePlayPolicy.RefreshDuration
    });
```

## 场景接入

在需要魔女时间的场景中放一个普通 GameObject，并挂载 `WitchTimeExecutor`。它不是 MonoSingleton，也不需要 VContainer 硬注入；只通过 `GameApplication.Instance.EventCenter` 接收和广播事件。

如果后续要接 UI 或屏幕效果，新建监听者即可：

```text
WitchTimeScreenEffect
    监听 OnWitchTimeStarted -> 开始后处理 / 屏幕特效
    监听 OnWitchTimeUpdated -> 更新进度
    监听 OnWitchTimeStopped -> 关闭效果

WitchTimeHud
    监听 OnWitchTimeStarted -> 显示提示
    监听 OnWitchTimeUpdated -> 更新进度条
    监听 OnWitchTimeStopped -> 隐藏提示
```
