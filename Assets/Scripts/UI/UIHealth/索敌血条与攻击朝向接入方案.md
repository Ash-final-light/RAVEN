# 敌人血条显示与攻击目标接入方案

## 需求结论

敌人血条不再只跟随索敌目标刷新。

正式规则改为：

1. 如果玩家最近一次攻击命中了敌人，敌人血条显示该被命中的敌人。
2. 如果玩家还没有攻击命中过敌人，敌人血条显示当前索敌目标。
3. 如果最近攻击目标死亡、离场或失效，则清空最近攻击目标，并回退到当前索敌目标。
4. 如果既没有最近攻击目标，也没有索敌目标，则隐藏敌人血条。

这个方案覆盖原本的血条更新机制。原本“锁定谁就显示谁、资源变化只刷新锁定目标”的逻辑废弃，改为“显示目标由玩家最近攻击目标优先决定，索敌目标只作为 fallback”。

## 显示目标优先级

敌人血条当前显示目标由 `FightUILockTargetHealthBinder` 统一决策：

```text
displayTarget =
    lastPlayerHitTarget != null
        ? lastPlayerHitTarget
        : currentLockTarget
```

目标说明：

- `lastPlayerHitTarget`：玩家最近一次攻击实际造成命中/伤害的敌人。
- `currentLockTarget`：当前索敌系统选中的敌人。
- `displayTarget`：UI 当前绑定并显示血条的敌人。

UI 不直接遍历 `BattleManager.Data` 找敌人，也不自己判断距离、朝向、优先级。

## 事件来源

### 1. 玩家命中敌人事件

命中来源使用战斗结算后的资源变化事件：

```csharp
BattleManager.OnCharacterResourceChanged(CharacterProperty target, DamageInfo damageInfo)
```

当满足以下条件时，更新 `lastPlayerHitTarget`：

- `damageInfo.AttackerId` 是玩家角色 id。
- `target` 不为空。
- `target` 是敌方单位。
- 这次变化来源是伤害或有效命中，不是敌人自我恢复、环境回血等非玩家攻击来源。

推荐首版判断：

```csharp
private bool IsPlayerHitEnemy(CharacterProperty target, DamageInfo damageInfo)
{
    return target != null
        && damageInfo.AttackerId == playerCharacterId
        && damageInfo.TargetId == target.gameObjId
        && !damageInfo.Type.IsHeal();
}
```

如果后续有召唤物、子弹、机关归属，需要把 `DamageInfo` 中的攻击归属统一映射到玩家 owner id。

### 2. 索敌目标变化事件

继续保留当前索敌入口：

```csharp
MainCameraController.CurrentLockTarget
MainCameraController.OnLockTargetChanged
```

索敌目标变化时只更新 `currentLockTarget`，不一定立刻替换血条显示目标。

如果 `lastPlayerHitTarget` 仍然有效，血条继续显示最近被玩家攻击的敌人；如果没有最近攻击目标，才显示新的索敌目标。

### 3. 目标失效事件

以下情况需要清空 `lastPlayerHitTarget`：

- 最近攻击目标死亡。
- 最近攻击目标从 `BattleManager.Data` 移除。
- 最近攻击目标对应 GameObject 被销毁。
- 最近攻击目标不再是敌方单位。

清空后立即重新计算 `displayTarget`，优先回退到 `currentLockTarget`。

## UI 刷新规则

`FightUILockTargetHealthBinder` 不再每帧刷新血条。

只在以下事件发生时刷新：

1. 玩家攻击命中敌人。
2. 当前显示目标的资源变化。
3. 索敌目标变化，且当前没有有效的最近攻击目标。
4. 当前显示目标死亡或失效。

刷新流程：

```text
事件触发
    |
    v
更新 lastPlayerHitTarget 或 currentLockTarget
    |
    v
ResolveDisplayTarget()
    |
    v
如果 displayTarget 变化：
    EnemySegmentedHealthBarDriver.Bind(displayTarget)
    EnemySegmentedHealthBarDriver.SetName(...)
    EnemySegmentedHealthBarDriver.RefreshFromTarget(true)

如果 displayTarget 未变化但资源变化：
    EnemySegmentedHealthBarDriver.RefreshFromTarget(false)
```

当 `displayTarget == null`：

```text
EnemyStatus 隐藏
```

## FightUILockTargetHealthBinder 职责

正式职责：

1. 订阅索敌目标变化事件。
2. 订阅战斗资源变化事件。
3. 记录玩家最近一次攻击命中的敌人。
4. 统一计算当前 UI 应显示的敌人。
5. 驱动 `EnemySegmentedHealthBarDriver` 绑定和刷新。

建议字段：

```csharp
[SerializeField] private MainCameraController cameraController;
[SerializeField] private EnemySegmentedHealthBarDriver enemyHpBar;
[SerializeField] private string playerCharacterId = "test1";
[SerializeField] private bool hideWhenNoTarget = true;

private CharacterProperty currentLockTarget;
private CharacterProperty lastPlayerHitTarget;
private CharacterProperty displayTarget;
```

核心接口：

```csharp
private void HandleLockTargetChanged(CharacterProperty target)
{
    currentLockTarget = target;

    if (!IsValidDisplayTarget(lastPlayerHitTarget))
    {
        lastPlayerHitTarget = null;
        ResolveDisplayTarget();
    }
}
```

```csharp
private void HandleCharacterResourceChanged(CharacterProperty target, DamageInfo damageInfo)
{
    if (IsPlayerHitEnemy(target, damageInfo))
    {
        lastPlayerHitTarget = target;
        ResolveDisplayTarget();
        RefreshDisplayTarget(false);
        return;
    }

    if (IsSameTarget(target, displayTarget))
    {
        RefreshDisplayTarget(false);
    }
}
```

```csharp
private void ResolveDisplayTarget()
{
    CharacterProperty nextTarget = IsValidDisplayTarget(lastPlayerHitTarget)
        ? lastPlayerHitTarget
        : currentLockTarget;

    if (IsSameTarget(displayTarget, nextTarget))
    {
        return;
    }

    displayTarget = nextTarget;
    BindDisplayTarget();
}
```

## 敌人名字显示规则

显示名优先级：

```text
CharacterProperty.Info.Name
    -> CharacterProperty.gameObjId
    -> GameObject.name
```

血条驱动只负责显示，不负责选择目标。

## 与原机制的差异

原机制：

```text
索敌目标变化 -> 绑定血条
当前索敌目标资源变化 -> 刷新血条
```

新机制：

```text
玩家命中敌人 -> 该敌人成为血条主显示目标
主显示目标资源变化 -> 刷新血条
主显示目标失效 -> 回退到索敌目标
没有命中记录 -> 使用索敌目标
```

因此，当玩家锁定 A，但攻击命中 B 时：

```text
血条显示 B
```

当玩家还没有命中过任何敌人，但锁定 A 时：

```text
血条显示 A
```

当 B 死亡或失效，且当前锁定 A 时：

```text
血条回到 A
```

## 验证用例

1. 进入 `PlayerTest`，不攻击，只索敌 `test_enemy`。
   - 预期：敌人血条显示索敌目标。

2. 玩家没有索敌，攻击命中 `test_enemy`。
   - 预期：敌人血条显示 `test_enemy`。

3. 玩家锁定 A，但攻击命中 B。
   - 预期：敌人血条切换并显示 B。

4. 玩家最近命中 B，此时切换索敌到 A。
   - 预期：血条仍显示 B。

5. B 死亡或失效，当前索敌为 A。
   - 预期：血条回退显示 A。

6. B 死亡或失效，当前没有索敌目标。
   - 预期：敌人血条隐藏。

## 注意事项

- “最近一次攻击敌人”必须以战斗结算事件为准，不以攻击按键或动画开始为准。
- UI 不应该根据玩家面向、距离或碰撞盒自行推断攻击目标。
- 索敌只提供 fallback，不再拥有血条显示的最高优先级。
- 多玩家模式下，事件需要携带玩家 id，`lastPlayerHitTarget` 应按玩家维度分别记录。
