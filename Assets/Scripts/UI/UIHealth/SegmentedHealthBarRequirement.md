# 分段血量显示机制需求说明

## 需求背景

当前血量需要拆分成多段进行显示。界面上只显示一段血条的填充状态，同时在血条右侧通过倍率文本展示当前血量对应的段数，例如 `x5`。

该机制用于在单条血条承载固定显示上限时，表达角色或单位拥有多段血量的状态。

## 核心规则

1. 血条本体只展示当前段的血量填充比例。
2. 血条右侧显示当前血量对应的段数，格式为 `xN`。
3. 每段血量的显示上限为 `100`。
4. 当前血量大于一段血量时，通过右侧倍率数字表示剩余段数。
5. 当倍率数字大于 `1` 时，血条填充框底部显示浅灰色底。
6. 当倍率数字等于 `1` 时，血条填充框底部为透明底。

## 显示示例

| 当前血量 | 血条显示含义 | 右侧倍率 | 填充框底部 |
| --- | --- | --- | --- |
| 500 | 血条代表 100 血量的一段 | x5 | 浅灰色 |
| 400 | 血条代表当前最后一段显示 | x1 | 透明 |

## 视觉表现

血条由两部分组成：

1. 血量填充条：表示当前显示段的血量状态。
2. 右侧倍率文本：显示当前血量被拆分后的段数，格式为 `xN`。

当 `N > 1` 时，填充框底部需要出现浅灰色背景，用于提示当前仍存在多段血量。

当 `N = 1` 时，填充框底部不显示背景，保持透明，用于表示当前已进入最后一段血量。

## 交互与刷新规则

1. 血量变化时，需要同步刷新血条填充比例、右侧倍率文本和填充框底部状态。
2. 倍率文本需要始终显示在血条右侧。
3. 倍率文本中的数字应根据当前血量计算得出。
4. 当血量降到只剩最后一段时，倍率文本显示为 `x1`，填充框底部切换为透明。

## 验收标准

1. 当前血量为 `500` 时，血条按一段 `100` 血量显示，右侧显示 `x5`，填充框底部为浅灰色。
2. 当前血量为 `400` 时，右侧显示 `x1`，填充框底部为透明。
3. 当右侧倍率数字大于 `1` 时，填充框底部始终为浅灰色。
4. 当右侧倍率数字等于 `1` 时，填充框底部始终为透明。
5. 血量变化后，血条、倍率文本和底部背景状态能够即时更新。

## 备注

当前需求重点描述 UI 表现逻辑。具体血量段数的计算方式、动画过渡、扣血表现和与战斗系统的数据对接，可在实现阶段根据现有血量系统进一步补充。
